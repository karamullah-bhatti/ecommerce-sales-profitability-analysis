# E-Commerce Sales & Profitability Analysis

## Overview
An Excel-based data analysis project exploring e-commerce sales, profitability, product performance, and business trends through an interactive dashboard.

## Tools
- Microsoft Excel 2013
- PivotTables & PivotCharts
- Excel Formulas
- Interactive Slicers

## Dashboard Preview
![Dashboard](screenshots/dashboard.jpg)

## Key Analysis
- Regional Sales & Profit
- Product Performance
- Monthly Sales Trends
- Customer Segment Analysis
- Salesperson Performance
- Order Status Analysis

## Key Insights
- West generated the highest regional sales and profit.
- Electronics generated the highest category sales and profit.
- Beauty achieved the highest profit margin.
- Usman generated the highest salesperson profit.

Synthetic dataset created for educational and portfolio purposes.
